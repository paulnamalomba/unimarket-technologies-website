# Unimarket Technologies Prototype Decisions

## Implemented

- Replaced the inherited source with a four-page Next.js prototype.
- Used the Nuxt UI SaaS template as a compositional reference only.
- Kept Next.js App Router, React, TypeScript, Tailwind CSS, and `next/image`.
- Applied the Unimarket Technologies logo-derived palette and Inter typography.
- Added shadcn/ui-inspired semantic tokens and typed button variants.
- Standardized interface iconography on Lucide React.
- Used the exact supplied PNG logo.
- Added generated photographic imagery instead of vector placeholders.

## Four-page scope

1. Home.
2. Solutions overview.
3. POS + MRA EIS solution detail.
4. Contact / request a consultation.

UX/UI, website development, full-stack applications, enterprise software, process, and proof framing are represented inside these pages.

## Nuxt template cues retained

- High-clarity SaaS hero.
- Layered product media.
- Alternating split sections.
- Feature and capability grids.
- Restrained borders, surfaces, and shadows.
- Strong closing CTA panels.

No Nuxt/Vue implementation or template branding is used.

## Deliberately unclaimed

- Phone, email, office, and social details.
- Customers, testimonials, partnerships, certifications, and metrics.
- MRA accreditation or completed integration.
- Specific card-machine or payment-provider relationships.
